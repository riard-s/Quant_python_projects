# Quant_python_projects

Project 1: 
Card Draw Monte Carlo Simulator 
  The project simulates drawing cards from a deck of 52 cards without replacement, then it compares the simulated average value with the theoretical EV (which is 7). I ran the code with a variety of numbers of hands from 100 to 1000000 to show that the average value converges to 7, therefore proving the law of large numbers.

Project 2:
Stock Price Simulator
  This models a stock price over 252 days using a random walk starting at £100. Each day's price moves randomly by a random amount. It is tracked throughout the whole time period and outputs the last price, the max and the min.
